# 写作示例与边界

本页所有场景均为**假设画面描述**，用于文本行为检查，不是上传照片，也不表示完成了真实图像识别。前三例是完整创作；第四例在第一例基础上修改。真实演示照片及其成品另见 `demo/`。

## 1. 海边落日 · 温柔治愈

输入：假设画面描述——橙色天空、海面反光、岸边脚印。心情：旅行最后一天，有点舍不得。收件人：未来的自己。

根据你描述的橙色天空、海面反光和岸边脚印，写一张寄给未来自己的明信片，留住一点舍不得。

【明信片正面】

标题：把这一刻留下

照片短句：岸边的脚印还在，我想再看看这片橙色的天。

【明信片背面】

收件人：未来的自己

故事正文：

旅行到了最后一天，最舍不得的，竟是这样简单的一幅画面：天空铺着橙色，海面接住一片反光，岸边还留着脚印。照片只收下了眼前这些，我却想让它在手里多停一会儿，不急着给这趟旅行写结尾。

以后再翻到这里，不知道你会先看见哪一处。我想先看看那些脚印。它们让这片海不只是一张风景，也留住了此刻不太想离开的心情。

寄语：等你再读到这里，记得这一天曾舍不得结束。

【排版建议】

- 推荐横版；照片完整放在正面上部，标题与短句置于下方独立奶白文字区。假设描述未给尺寸，拿到原图后再调整方向。
- 背面正文靠左分两段，寄语放下部；未提供署名，不留虚构落款。
- 推荐配色：奶白 `#fff9ee`、深蓝灰 `#283e45`、陶土 `#92543e`，不是照片采样。
- 标题用宋体类别，备选 Songti SC、SimSun；正文用黑体类别，备选 PingFang SC、Microsoft YaHei、sans-serif。保留海面反光和岸边脚印，深色字配浅底，四周留白。

可以继续说：改成寄给妈妈 / 更口语化 / 缩短到 80 字。

## 2. 雨后街巷 · 轻快俏皮

输入：假设画面描述——湿润石板路、屋檐、暖黄色店铺灯光。心情：一个人走走，反而轻松了。收件人：朋友。

根据你描述的湿石板路、屋檐与暖黄店灯，用轻快的口气把这份轻松分享给朋友。

【明信片正面】

标题：这条小巷不赶路

照片短句：石板路亮着，屋檐下的灯也来凑个热闹。

【明信片背面】

收件人：朋友

故事正文：

给你看看这条雨后的巷子。石板路湿润润的，屋檐下面亮着暖黄色的店灯，像是整条街给自己开了一盏小台灯。没有什么惊天动地的发现，但我挺想把这幅画面寄给你。

一个人走走，反而轻松了。不必非得走出一条值得推荐的路线，看看路面，再看看灯，也算认真逛过。今天的旅途汇报就这些，内容不多，小巷倒很会撑场面。

寄语：把这条亮着小灯的巷子寄给你，供你闲时看看。

【排版建议】

- 推荐竖版以顺应街巷纵深，照片放正面上部，标题和短句放底部独立浅色区。
- 背面左对齐两段正文，寄语与正文间留一行，未给落款就省略。
- 推荐配色：米白 `#f7f1e6`、石墨 `#343b3b`、暖棕 `#86552f`；正文使用前两色保证反差。
- 标题、正文都可用黑体类别，备选 PingFang SC、Microsoft YaHei、sans-serif。保留屋檐、灯和石板路，不把字压在反光上；方向待实际图片确认。

可以继续说：改成寄给妈妈 / 更口语化 / 缩短到 80 字。

## 3. 山间云海 · 简洁纪实

输入：假设画面描述——层叠山脊、云层、观景栏杆。心情：终于给自己放了个假。收件人：父母。语气：像平时说话。

根据你描述的层叠山脊、云层和栏杆，用平常说话的口气写给父母。

【明信片正面】

标题：给你们看看山

照片短句：栏杆外是层层山脊，云在山间铺开了。

【明信片背面】

收件人：爸爸妈妈

故事正文：

爸、妈，给你们寄一张山里的照片。近处是观景栏杆，后面是层层叠叠的山脊，云铺在山间，几处山的轮廓还露在外面。想让你们看看，我眼前的景色是什么样的。

终于给自己放了个假，这句话写下来还挺开心。这张照片里没有太多东西，我最想留下的就是这些山和云。等你们看到，也可以挑一处喜欢的地方，告诉我你们先注意到了什么。

寄语：先把山里的这幅景色寄给你们，想听听你们怎么看。

【排版建议】

- 推荐横版展示山脊层次，照片完整保留；标题和短句放下边框，不盖住云海。
- 背面正文左对齐，寄语另起一块；未提供署名，不自动添加“你们的孩子”。
- 推荐配色：云白 `#f4f5f0`、山青 `#304c4a`、灰绿 `#66756a`，不是精确采样。
- 正文用黑体类别，备选 PingFang SC、Microsoft YaHei、sans-serif；标题可用 Songti SC、SimSun。保留栏杆作为前景参照，浅底深字，正文行距约 1.8～2 倍。

可以继续说：更口语化 / 缩短到 80 字。

## 4. 同图修改 · 从未来的自己改寄妈妈

沿用第一例的**假设画面描述**和“旅行最后一天，有点舍不得”。修改指令：“改成寄给妈妈，少一点文艺感。”不新增城市、同行者、行程安全或私人回忆。

仍用橙色天空、海面反光和岸边脚印，改成给妈妈分享眼前景色，语气更家常。

【明信片正面】

标题：给你看看这片海

照片短句：妈，天空橙橙的，海面上也亮着一片光。

【明信片背面】

收件人：妈妈

故事正文：

妈，给你看看这张海边照片。天空是橙色的，海面上有一片反光，岸边还能看见脚印。这趟旅行到了最后一天，我有点舍不得，就想把眼前的样子留下来，也给你看看。

照片里我最喜欢那片海上的亮光，看着它，觉得这一张值得寄给你。没有什么特别的事要交代，就是想分享一下。等你看到这张明信片，告诉我你最喜欢照片里的哪一处吧。

寄语：把最后一天看到的海寄给你，等你说说喜不喜欢。

【排版建议】

- 沿用横版、完整照片和底部独立文字区，仅替换标题与短句。
- 背面更换为上方称呼、两段家常正文和下方寄语；无地点、日期、署名。
- 推荐配色仍为奶白 `#fff9ee`、深蓝灰 `#283e45`、陶土 `#92543e`；保留留白和浅底深字。
- 标题 Songti SC / SimSun，正文 PingFang SC / Microsoft YaHei / sans-serif；不裁掉脚印或反光。

检查要点：从“给未来自己的记录”改为“向妈妈分享并邀请回应”，不是只替换收件人。

## 5. 图片无法读取

输入：用户上传图片但当前工具读取失败，用户说“帮我做成明信片”。**没有可确认的假设画面描述。**

正确回复：“我这次没能读取到图片。请用一句话描述画面，比如主要景物和颜色，我就能继续写明信片。”

不要接着写“照片里的海很蓝”；不要拿 `demo/sample.jpg` 顶替。用户补充描述后按描述创作，并说明来源；没有原图时不声称生成了原照片成品。

## 6. 只给照片、没给心情

测试输入：当前对话已明确要制作明信片；**假设画面描述**为“一条木栈道向远处延伸，两侧是草”。未给其他信息。

应直接采用未来的自己、平实语气，省略地点日期署名，不连续追问。可用标题“栈道两旁的草”，短句“木栈道伸向远处，两边的草留在画面里。”故事记录栈道和草，不写“终于走出了低谷”“此刻无比自由”等未经提供的情绪。新对话仅上传无任务照片时，不因有照片就自动套用技能。

## 7. 信息不足的夜景

测试输入：**假设画面描述**为“黑暗背景中一处亮灯，模糊招牌无法辨认”。用户想给照片写背面文字，未给心情。

应明确以“黑暗中那处亮灯”为仅有的可靠细节，可以写短于默认长度的作品；不凑霓虹、雨水、人流，不猜城市或店名，不把孤身、悲伤、失恋当事实。

复古书信风格的局部写法示意（不是第四个完整场景）：“给未来的自己：留此一笺，记下画面里那处灯光。”可以有书信节奏，但不写“昔日共游此地”一类伪造往事。
